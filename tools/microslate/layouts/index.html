MicroSlate · Keyboard layouts

Type in your own language.

MicroSlate has US QWERTY built in. Every other layout is a small text file: download the one for your keyboard, copy it to the SD card and pick it in Settings. Needs MicroSlate 3.0.

Install a layout

  1. 1

    Download

    Pick the file for your keyboard from the list below.

  2. 2

    Copy to the card

    Put the SD card in a computer and copy the file into microslate/layouts/. Create the layouts folder if it isn't there.

  3. 3

    Pick it

    Put the card back and choose it in Settings > Keyboard layout. Ctrl+K or Win+Space switches layouts while you write.

Copy only the layouts you use. Every file in the folder joins the switching order. A short tag such as DE at the top of the screen shows which one is active.

Want to choose on your computer? Download all 32 layouts (zip), then copy only the ones you need.

Change a key on the device

Go to Settings > Edit keyboard layout and press the key you want to change. You see what it types on its own, with Shift, and with AltGr on layouts that use it. Pick a row, type what it should type, then Save. Reset puts one key back and Reset all undoes every change.

Your changes never touch the layout file. They're kept in their own small file in microslate/layouts/changes/, so a newer copy of a layout keeps your fixes, and deleting that file undoes them.

Write your own

A layout file is plain UTF-8 text, one line per key, named after where the key sits on a US keyboard. Lines starting with # are comments. Open any file above in a text editor to see a full example.

name = Deutsch (QWERTZ)
short = DE
base = us

Y = z Z
Q = q Q @
EQUAL = dead:´ dead:`
SEMICOLON = ö Ö

Each key line lists what it types normally, with Shift, with AltGr and with Shift+AltGr. dead:´ makes an accent key (´ then e types é). base = us means you list only the keys that differ from US. A line with a mistake is skipped, and microslate/layout-problems.txt on the card says which line and why.

What's not covered yet

The MicroSlate fonts show Latin and Cyrillic letters. Greek, Hebrew, Arabic and Asian scripts can't be typed yet, and characters the fonts can't show were left out of these files.

The layouts are made from the Linux keyboard definitions (xkeyboard-config, MIT licence), so they type what the same layout types on a Linux PC.
